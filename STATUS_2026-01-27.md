## 🔍 What We Learned

### Database Structure
- **Location:** `data/leads.db` (SQLite)
- **Tables:** `leads`, `processing_log`, `exports`
- **Status tracking:** `enrichment_status`, `scrape_status`, `gemini_status`, `personalization_status`
- **Persistence:** Progress is saved after each lead, so pipeline can be stopped/resumed

### Rate Limiting Reality
Your paid AI Studio key should support **~1,500 requests per minute**, but the pipeline enforces a **1-second delay between requests** (hardcoded in `app.py` line 827). This is intentional to:
- Prevent overwhelming the API
- Stay well below quota limits
- Avoid triggering abuse detection

**Expected throughput:** ~60 leads/minute during AI enrichment phase

### Pipeline Behavior
Each lead goes through 4 sequential steps:
1. **Google Places enrichment** (~1s per lead)
2. **Website scraping** (~2-5s per lead, depends on site)
3. **Gemini AI enrichment** (~2-3s per lead + 1s rate limit delay)
4. **Scoring calculation** (instant, local)

**Bottleneck:** Web scraping and Gemini AI (Steps 2-3)

## 🔧 Troubleshooting Guide

### If You Still See Rate Limits:
1. **Check API Key Tier:**
   - Go to [Google AI Studio](https://aistudio.google.com/)
   - Verify you're on a paid plan
   - Check quota usage dashboard

2. **Reduce Batch Size:**
   - Default batch size is 10 leads at a time
   - Try reducing to 5 or even 1 for testing
   - In web UI: adjust batch size slider

3. **Check for Concurrent Requests:**
   - Only run ONE pipeline at a time
   - Don't run manual enrichment while pipeline is running
   - Check browser devtools for duplicate requests

4. **Monitor with Increased Backoff:**
   - The new 5-retry system should handle transient limits
   - If still failing after 5 retries, quota is exhausted
   - Wait 60 seconds and try again

### If Database Issues:
- **Missing leads.db:** Normal! Created on first upload
- **Permission errors:** Check `data/` folder permissions
- **Corruption:** Delete `data/leads.db` and re-upload (loses progress)
